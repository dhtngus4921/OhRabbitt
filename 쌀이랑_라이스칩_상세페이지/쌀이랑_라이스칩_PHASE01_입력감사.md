# 우리쌀 라이스칩 — PHASE 01 입력 감사

## 1. 입력 현황

- 상품명: 우리쌀 라이스칩 (사용자 최종 정정)
- 카테고리: 가공식품 / 과자류 / 구운 쌀과자
- 주요 판매 채널: 쿠팡(마스터 가이드 기준, 최종 확인 필요)
- 제공된 원고: 상품 소개, 핵심 특징, 5개 옵션 소개, 포인트 구성, 메인 카피, 섭취 상황, 이미지 요청서, 표현 검수 주의사항
- 제공된 템플릿: `C:\Codex\template-reference.png` (860×13,200px)
- 실제 상품 사진: 미제공
- 표시사항·영양정보·인증서: 미제공

## 2. 템플릿 분석

제공 템플릿은 아래의 구조와 리듬만 참고한다.

1. 상단 브랜드·신뢰 메시지
2. 상품명과 핵심 혜택을 빠르게 알리는 HERO
3. 실제 원물/상품 풀샷
4. 번호형 카드로 설명하는 핵심 포인트
5. 옵션·구성 카드
6. 이용·보관·주의사항
7. 차분한 상품정보표

초록 농장 팔레트, 옥수수 사진, 기존 문구와 장식은 쌀이랑에 재사용하지 않는다.

## 3. 확정 가능한 상품 사실

아래는 사용자 제공 원고에 명시된 내용이다. 다만 최종 게시 전 실제 포장 표시사항과 대조한다.

- 쌀을 주원료로 만든 라이스칩
- 당해년도 수확 햅쌀 사용
- 기름에 튀기지 않고 1차 압착 후 추가로 살짝 구운 제품
- 밀가루를 사용하지 않은 제품
- 과하게 달지 않고 담백한 맛을 지향
- 5가지 맛: 검정콩과 현미보리 / 치즈 / 양파와 새우 / 커피 / 쌀이랑 김이랑
- 원고상 GMO 원료 미사용
- 원고상 HACCP 인증 시설 생산
- 원고상 백화점·대형마트·휴게소 등 오프라인 판매 이력

## 4. 표현 상태 분류

### A. 포장 표시사항 대조 후 사용

- `당해년도 수확 햅쌀`
- `기름에 튀기지 않고 구운`
- `밀가루 미사용`
- 맛별 원재료명·함량·원산지
- `달지 않고` 표현은 영양정보와 맛 설계를 확인해 `과하게 달지 않은 담백한 풍미`로 절제해 사용

### B. 근거 자료 확인 전 본문 사용 보류

- `GMO FREE` / GMO 원료 미사용
- `Gluten Free`
- `무트랜스지방`
- `첨가물 없음`
- `100% 국산 우유`
- `천연치즈`
- `HACCP 인증 시설 생산`
- 백화점·대형마트·휴게소 현재 판매

### C. 현재 문구의 정제가 필요한 부분

- `대부분의 원료를 국내산으로` → 맛별 원산지를 개별 확인한 후 구체적인 원료만 표기
- `국산 원료 중심` → 국내산으로 확인된 원료를 맛별로 열거
- `신선한 맛` → 객관적 선도 판정으로 읽히지 않도록 `당해년도 햅쌀의 담백한 풍미`로 표현
- `매일 부담 없이` → 영양·건강 혜택을 암시하지 않도록 `일상에서 가볍게 즐기는 간식`으로 표현

## 5. BLOCKING / NEEDED LATER / OPTIONAL

### BLOCKING — GATE 02 이전 필요

- 5개 옵션의 실제 패키지 정면 사진 또는 누끼
- 실제 라이스칩 접사 사진
- 실제 판매 구성: 낱개·세트 여부, 맛별 중량, 총 수량
- 맛별 한글 표시사항 전면 사진

### NEEDED LATER — 상품정보·신뢰 섹션 완성 전 필요

- 식품의 유형, 내용량, 제조원, 소재지, 유통기한 또는 소비기한, 보관방법, 포장재질
- 원재료명 및 함량, 원산지, 알레르기 유발물질
- 영양정보
- HACCP 인증서 또는 정식 인증 표시 확인 자료
- GMO 원료 미사용 표현의 사용 가능 근거
- 교차접촉 가능성을 포함한 밀가루/글루텐 관련 표시 근거
- 현재 오프라인 판매처와 로고 사용 권한
- 제조사, 유통전문판매원, 판매원 등 실제 법적 역할명과 사업자명
- 반품·교환 기준, 소비자 상담 연락처

### OPTIONAL

- 판매가격과 가격 포지셔닝
- 주요 고객 연령대
- 실제 제조 공정 사진
- 실제 오프라인 매장 진열 사진
- 추가 촬영 가능 여부
- AI 배경 합성 허용 범위

## 6. 입력 감사 결론

- 작업 모드: **EXTENDED**
- 이유: 5개 맛 옵션, 식품 표시사항, 인증·원산지·무사용 표현 검수가 필요하며 사진 역할이 다양함
- 현재 가능 단계: **PHASE 01 기획안 확정**
- 현재 불가능 단계: 실제 상품 사진과 표시사항 없이 GATE 02 통과 및 최종 HTML/분할본 완성
