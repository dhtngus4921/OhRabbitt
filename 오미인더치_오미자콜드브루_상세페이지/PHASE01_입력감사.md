# 오미인더치 오미자 콜드브루 차 — PHASE 01 입력 감사

## 확보된 근거 자료

- 사용자 제공 상세페이지 원고
- 제품 표시사항 이미지: `assets/references/제품표시사항_원본.png`
- 문경 산지 정보: 문경시 공식 오미자 소개 페이지
- 오미자 씨 성분 참고: 오미자 부위별 리그난 분석 학술자료

## 사용자 요청 반영 상태

1. 문경이 오미자 제1주산지이자 지역 특산물이라는 메시지를 ORIGIN 섹션으로 강화한다.
2. 분말 가공으로 씨까지 활용하고 콜드브루 방식으로 추출한 이유를 별도 PROCESS 섹션으로 구성한다.
3. 첨부 이미지의 영양정보, 제품정보, 보관방법과 주의사항을 정보 영역에 반영한다.

## 표현 강도 판정

| 표현 | 상태 | 적용 방식 |
|---|---|---|
| 문경은 전국 오미자 제1주산지 | 사용 가능 | 문경시 공식 자료 기준 문구 병기 |
| 전국 생산량 약 45%, 연간 약 1,500톤 | 사용 가능 | 자료 시점에 따라 달라질 수 있다는 각주 병기 |
| 오미자를 분말 가공해 씨까지 활용 | 사용자 제공 공정 사실 | 제조 공정서 확보 권장 |
| 낮은 온도에서 천천히 추출 | 사용자 제공 공정 사실 | 실제 추출 온도·시간 확보 권장 |
| 성분 손실 최소화 | 조건부 | 완제품 비교 시험 또는 공정 자료 확보 후 강화 |
| 씨 영양소를 모두 섭취·흡수 가능 | 사용 보류 | 전 성분 보존과 체내 흡수를 보장하므로 근거 부족 |
| 오미자 씨에 리그난이 존재 | 일반 학술 근거 있음 | 완제품 함량·기능성 주장으로 확장 금지 |
